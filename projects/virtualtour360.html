Turn physical spaces into interactive 360° experiences.

Workflow at a glance

A CLOSER LOOK AT THE PRODUCT

What VirtualTour360 actually includes

A full virtual-tour creation and publishing platform, with interactive navigation, location context and usage analytics.

01

Panorama import and assets

Bulk import wizard supports media selection, review and ordering, with generated thumbnails.

02

Tour and scene editor

Build tours from scenes, manage scene order and edit the viewing experience.

03

Interactive hotspots

Supports styled hotspots that link scenes or present contextual information.

04

Visual scene graph

Scene linking can be managed through a node-and-connection editing view.

05

Immersive viewer

Source documents autorotation, gallery, gyroscope, stereo viewing, deep links and keyboard navigation.

06

Floor plans and mini-map

Tour authoring includes floor plans and scene pins; published viewing can show position and orientation.

07

Controlled publishing

Includes public-sharing flows, a password gate, branding controls and embeddable tour views.

08

Audience analytics

Records viewing sessions and hotspot interactions, with per-scene engagement and dashboard breakdowns.

TECHNICAL DEEP DIVE

Architecture and stack

Tour editor

React 19, TypeScript, Vite and Photo Sphere Viewer provide the interactive editing and viewing UI.

API

Express and TypeScript implement tour, scene, sharing and analytics functionality.

Metadata & media

Prisma and PostgreSQL store project data; MinIO and Sharp process image assets.

Published experience

Scene links, hotspots, viewer plugins and floor plans enable navigation.

Technology stack

React · Vite · Three.js · Photo Sphere Viewer · Express · Prisma · PostgreSQL · MinIO · Sharp

Rendering and analytics

Supported viewer features include gyroscope, stereo, autorotation, scene transitions and a mini-map. Recorded viewer events enable tour and hotspot analytics.
