Company Hub

One workplace for staff services and business applications.

Workflow at a glance

Employee workspace→Connected services→Business applications
A CLOSER LOOK AT THE PRODUCT

What Company Hub actually includes

More than an employee portal: a connected business workspace spanning people, documents and operational systems.

01

Unified app entry point

Brings internal services and connected applications into a common staff-facing workspace.

02

Role-based dashboards

Includes dashboard components and integrations for common users and departmental views, including projects, HR, finance and procurement.

03

Documents and letters

Source includes employee document workflows, letters, document libraries and content management.

04

Digital signatures

Supports document-signature interfaces, recipients and signature-handling workflows across the platform.

05

Approvals and requests

Includes approval, notification and pending-request views for everyday work.

06

Collaboration tools

Staff-facing interface includes chat, activity views and notifications.

07

Connected business data

A dedicated backend mediates dashboard and application data from the underlying ERP and related services.

08

Administration and access

Backend includes administration for users, departments, projects, application access and service APIs.

TECHNICAL DEEP DIVE

Architecture and stack

Web application

Next.js 16, React 19, TypeScript and Tailwind CSS power staff-facing screens.

Backend services

Laravel 12 provides application APIs, workflows and administrative services.

Enterprise integration

Odoo ERP and Microsoft services provide connected business information.

Data and collaboration

MySQL, Filament administration and Laravel Reverb components.

Engineering design

The web application consumes backend APIs, with permission-aware access to department dashboards and staff services.

Validation

Project source includes API and user-interface tests. Runtime verification of every integration is not established in this portfolio.

Source: frontend README and package manifest; backend README, dependency manifest and integration documentation.

Why it matters

Separate applications make routine work and access to company services fragmented.

The solution

A connected employee workspace bringing together dashboards, documents, signatures, letters, chat and navigation to linked business systems through integrated backend services.

What it covers

  • Unified access to services
  • Documents and staff workflows
  • Frontend, backend and ERP integration

My involvement

Platform concept, cross-application integration and coordination of solution delivery.
