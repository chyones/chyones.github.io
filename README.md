# Personal project site

Source for the public project overview at [chyones.github.io](https://chyones.github.io/).

## Purpose

A concise professional overview of ELV, ICT and IT infrastructure experience, systems integration, and selected AI / digital transformation projects. The six public case studies are descriptions, **not** mirrors of private application repositories.

## Structure

- `index.html` — professional overview and the six selected projects.
- `projects/` — individual project summaries and workflow diagrams.
- `assets/styles.css` — responsive styling; no build system required.
- `assets/favicon.svg` — simple identity mark.

## Editing

Edit the HTML pages and stylesheet on a feature branch and open a pull request. Check desktop and mobile presentation, page titles, links and accessibility before merging. GitHub Pages serves the default branch.

## Publication boundaries

- Do not copy source code, internal URLs, customer records, employee information, credentials, or unpublished configuration from private repositories.
- State project status accurately; do not suggest production readiness when only source or test evidence exists.
- Credit the upstream Hermes Agent project for the foundation of Company Agent.
- Project details may be shared on request only when appropriate and authorized.
